# Connector brand artwork

Official application artwork used to identify recommended connectors. Each image is bundled locally; the connector page does not depend on third-party image requests.

See [sources.json](sources.json) for the official source page, original asset URL, normalization notes, and SHA-256 of each PNG. Logos and trademarks remain the property of their respective owners; inclusion identifies the service and does not imply endorsement.

Keep each asset name aligned with its curated connector ID in `mcpRecommendationCatalog.ts`. Preserve proportions and colors.
