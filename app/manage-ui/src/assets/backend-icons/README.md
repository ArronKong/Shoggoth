Unmodified SVG exports from [Shoggoth Design, node 251:1385](https://www.figma.com/design/DH1TYfd4QTE78FLEi6d99F/Shoggoth-Design?node-id=251-1385).

`BackendTabIcon` uses these monochrome glyphs as CSS masks so selected states and dark mode inherit the tab color. Management tabs use a 16px icon frame; Dashboard uses the same assets at 12px, matching node 252:3077. The Shoggoth, OpenClaw, and Claude exports contain the inner glyph, with their frame insets preserved in the component stylesheet.
