# Shoggoth 产品统计隐私说明

更新于 2026-11-11。

在启用产品统计的正式桌面版本中，「使用统计」和「分享功能使用情况」默认开启。你可以随时到 **设置 → 隐私与统计** 修改。关闭总开关会停止两档统计并清除未发送的数据，单独关闭详细统计会保留基础活跃统计。升级会保留你的关闭选择。

维护者用统计数据了解活跃安装、版本分布、功能采用和操作质量。活跃按 UTC 日期和随机安装 ID 计算。每份应用数据目录使用一个随机 ID，每天首次真正操作前台窗口时记一次活跃。

## 采集内容

| 范围 | 数据 |
| --- | --- |
| 基础活跃 | 随机安装 ID、随机事件 ID、UTC 时间与日期、应用版本、系统类别、CPU 架构、数据格式和策略版本。 |
| 详细功能 | 主动使用的页面类别，单聊、群聊、灵感、任务、定时任务、模型、技能、助理和连接器操作的每日尝试、成功、失败和取消次数。群聊成功指用户消息已提交，任务和定时任务以操作请求可确认的结果为准。 |
| 操作质量 | 固定错误类别（网络、超时、需要认证、权限、不支持、验证失败、未知）及耗时区间（小于 1 秒、1–5 秒、5–30 秒、30–120 秒、120 秒及以上）。 |
| 配置与采用 | 已配置的后端、助理运行时、供应商和模型，以及聊天执行结果可确认的运行时、供应商和模型。记录已启用的公开连接器及类别、技能数量与来源类别、助理和配置数量。配置来自 App 成功读取的当前视图。没有读到的类别标记为缺失，未确认的执行结果归为未知。 |
| 配置转化 | 用户开始配置、明确触发的连接验证成功和首次聊天成功。每份应用数据目录每个步骤最多记一次。 |

详细功能在本地按 UTC 日汇总。公开供应商、模型和连接器名称只从随 App 发布的白名单取值，自定义条目只使用固定类别。每份汇总会带公开目录版本，以及适用的覆盖范围、截断或计数上限标记。

统计字段排除消息、提示词、回复、工具内容、聊天和任务正文、灵感便签、助理设定、搜索或输入内容、文件名和路径、URL、凭据、用户名、邮箱、账号及业务会话标识、精确 Token 用量、费用、日志、截图、录屏和硬件指纹。这些值的哈希也在排除范围内。

## 发送与保留

基础活跃和配置步骤会在记录后尝试发送。详细汇总在 UTC 跨天后封存，可能在下次启动时才发送。应用中的统计缓存最多保留 7 天。关闭会取消该档在途请求并清除待发送数据，重新开启只记录后续新操作及当时的配置快照。普通关闭会保留本地随机安装 ID 和用于防止重复计数的有限标记。

启用外发的版本经 HTTPS 将统计事件发送到 PostHog Cloud 美国区（`us.i.posthog.com`）。项目丢弃客户端 IP，应用禁用 GeoIP 补充和用户档案。接收方网络层可以看到连接的源 IP，随机安装 ID 可以关联同一安装多天的活动。按该项目当前的免费方案，云端产品统计事件保留一年。[PostHog 产品统计方案](https://posthog.com/product-analytics/pricing)

关闭统计无法撤回已经收到的数据。如有隐私问题或删除请求，请通过项目的 [GitHub Issues](https://github.com/ArronKong/Shoggoth/issues) 请求维护者提供后续联系渠道，公开帖子中请勿提交身份、密钥或安装标识。

上述开关控制 Shoggoth 产品统计。你主动使用的模型供应商、外部连接器和运行时按各自的设置与服务条款处理业务请求。
