## English

### What’s new

- Recent messages appear sooner when reopening a previously viewed native conversation. Older history loads in pages, and eligible conversations can continue in the same chat when their original runtime thread is retired.
- Chat shows reasoning effort options for the selected model and provider when support is known. Improve compatibility with Hermes, OpenCode, and Xiaomi MiMo, including a fix for repeated compaction with MiMo in the bundled Codex runtime.
- Scheduled tasks set to report changes only now suppress identical reports in both direct and group chats. Group reports stay in their assigned group, and silent runs remain visible in task history.

## 简体中文

### 更新内容

- 重新打开浏览过的原生会话时，近期消息会更快显示，较早的历史按页读取。原运行时线程退役后，符合条件的会话可在原聊天中接续。
- 已确认支持思考档位时，聊天会按所选模型和服务来源显示选项。改善与 Hermes、OpenCode 和小米 MiMo 的兼容性，包括修复内置 Codex 使用 MiMo 时的反复压缩问题。
- 设置为「仅报告变化」的定时任务，在单聊和群聊中都会对内容相同的报告去重。群报告留在绑定的群聊，静默运行仍可在任务历史中查看。
