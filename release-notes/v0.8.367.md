## English

- OpenCode chat and its model picker use the connected-provider catalog. This keeps sends and model selection working when the full provider catalog is large.
- OpenCode retries a confirmed context summary failure once. If it still fails, chat shows the final reason while preserving the thread and its history.
- Codex uses the model selected in chat when creating or resuming a thread and starting a turn. If the selection cannot be resolved, chat preserves the draft and asks for a model.
- The native Agent’s main session appears first in the session picker in both regular and immersive chat. The picker opens even when it has only the main session.

## 简体中文

- OpenCode 聊天和模型选择器改用已连接提供商的模型目录，修复全量目录过大时无法发送或选择模型的问题。
- OpenCode 上下文摘要确认失败后会自动重试一次。若仍失败，聊天会显示最后的具体原因，并保留原会话和历史记录。
- Codex 新建会话、恢复会话和启动回合时，都会使用聊天中选定的模型。暂时无法确认选择时，会保留草稿并提示选择模型。
- 普通和沉浸聊天的会话选择器优先显示原生 Agent 的主会话。只有主会话时也可展开选择器。
