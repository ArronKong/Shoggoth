## English

### What's new

- The default Shoggoth assistant can update another native assistant's settings from any of its direct chats when you explicitly name the target. The operation remains tied to the current chat and target assistant.
- Direct and immersive chats keep important progress messages and user interactions visible, while folding repetitive activity into the turn details. Tool activity also shows its name and status when a turn uses shared memory.
- Switching models in native chat carries forward the reasoning level when the target supports it, with a compatible fallback when needed. Model and assistant settings identify the built-in Codex runtime as Shoggoth.
- Setup can discover a local OpenClaw gateway and save an assistant's initial definition when the assistant is created.

## 简体中文

### 更新内容

- 在默认 Shoggoth 助理的任一直接会话中，可以明确指定另一位原生助理并修改其设定。操作会校验当前会话和目标助理。
- 普通单聊和沉浸聊天保留重要进度与用户交互，把重复动态折叠到回合详情中。使用借阅记忆的回合也会显示工具名称和状态。
- 原生聊天切换模型时，目标支持原有思考档位就继续使用，否则选择兼容档位。「模型」与助理设定中，内置 Codex 运行环境以 Shoggoth 标识。
- 首次配置可发现本机 OpenClaw 网关。创建助理时可保存初始设定。
