## English

### Changes

- **Faster group chat opening.** Group details show saved member cards immediately and refresh them in the background. Changes appear when the refresh finishes. A new group or member with no saved card still waits for the first load.
- **Cloud release reliability.** GitHub Actions retries temporary gateway errors while downloading the locked Electron version. The official installer verifies the archive checksum before extraction.

## 简体中文

### 更新内容

- **加快打开群聊。** 群聊详情先显示已保存的成员卡片，再在后台刷新。有变化时，刷新完成后更新显示。新群或新成员没有已保存的卡片时，仍会等待首次加载。
- **提高云端发布稳定性。** GitHub Actions 下载锁定版本的 Electron 时，遇到临时网关错误会自动重试。官方安装器会在解压前校验安装包的校验和。
