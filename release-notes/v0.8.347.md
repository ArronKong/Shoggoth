## English

- Model choices appear immediately and apply on the next turn. The last choice is saved for each conversation, including when you switch away while it is saving. Model menus and cold Codex startup are faster.
- Steer an active turn in supported runtimes and open verified output locations directly from chat.
- Added Agent Mail as an optional connector with managed CLI installation and authorization.
- Improved OpenCode recovery after interrupted turns and kept model selections across account and runtime changes.
- Agent archiving is blocked while accepted chat work is pending. Older archived agents recover their saved messages after a restart without running them again.

## 简体中文

- 模型点选会立即显示，并在下一轮生效。保存期间切换会话，各会话也会保留自己的最后一次选择。模型菜单和 Codex 冷启动更快。
- 支持的运行环境可以在回复进行中插话，也可以直接从聊天打开已核验的产物位置。
- 新增可选的 Agent Mail 连接器，支持受控安装 CLI 和授权。
- 改进 OpenCode 回合中断后的恢复，切换账号或运行环境时保留模型选择。
- 已接收的聊天任务仍待处理时，Agent 归档会被阻止。旧版已归档 Agent 的已保存消息可在重启后恢复，执行次数保持为零。
