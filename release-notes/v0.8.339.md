## English

### What's new

- Model selection for a configured provider now checks that provider's saved catalog and credentials. Reconnecting refreshes the model list and rejects results from an older connection.
- Web search can recover from a brief connection failure within its existing time limit. Requests with uncertain submission status keep their original result to avoid duplicate searches.
- Tool activity shows more specific, localized action names for terminal commands and product tools, consistently in live chat and history.
- Long replies that use shared memory can combine adjacent text and reasoning chunks while their sources are verified. This reduces interruptions from many small chunks while retaining source checks and output limits.
- Patched a file-matching dependency used by the build tools and the bundled Playwright library to prevent excessive CPU use while evaluating certain patterns.

## 简体中文

### 更新内容

- 为已配置的模型来源选择模型时，按该来源保存的目录和凭据核对。连接恢复后重新加载模型列表，并拒绝旧连接的迟到结果。
- 联网搜索可在原有总时限内恢复短暂连接故障。提交状态不确定的请求保留原结果，避免重复搜索。
- 终端命令和产品工具采用更具体的本地化动作名称，实时聊天与历史回看使用同一套展示规则。
- 使用共享记忆的长回复在核验来源期间，可以合并相邻的文本与思考分片，减少大量小分片造成的中断，同时保留来源核验和输出容量限制。
- 修复构建工具和内置 Playwright 使用的文件匹配依赖，避免特定匹配规则长时间占用 CPU。
