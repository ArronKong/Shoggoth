## English

- The Models page shows quota status for connected OAuth accounts. Grok usage and DeepSeek balance reads are available for supported sign-ins, with the latest successful reading kept for the same account.
- Native chat can hand longer jobs to background tasks, including Grok Build. Pending background approvals appear on the originating chat row and open the task details directly.
- Cron records missed schedules, recovers eligible runs, and includes group replies in run reports.
- Native chat reuses warmed Codex hosts and avoids repeating preparation for parked messages, reducing send latency when a conversation is waiting for capacity.
- Fixed native session rename, archive, and delete routing. Failed handoff summaries or unavailable models are handled per message, and OpenCode quota limits end affected model operations promptly.
- Model search shows matching entries without group headers. Dashboard activity focuses on agent runs and approvals.

## 简体中文

- 模型页显示已连接 OAuth 账号的额度状态。支持的登录方式可以读取 Grok 用量和 DeepSeek 余额，并保留同一账号最近一次成功读数。
- 原生聊天可以把较长的工作交给后台任务，新增对 Grok Build 的支持。待审批任务会在原聊天条目上提示，点击可直达任务详情。
- Cron 会记录错过的计划、恢复符合条件的任务，运行报告也可显示群聊回复。
- 原生聊天复用已预热的 Codex 进程，减少排队消息的重复准备，缩短等待执行容量时的发送延迟。
- 修复了原生会话重命名、归档和删除的路由。交接摘要失败或模型不可用时按消息处理，OpenCode 达到额度限制时会及时结束受影响的模型操作。
- 搜索模型时直接显示匹配结果，收起分组标题。仪表盘动态聚焦 Agent 运行和审批。
