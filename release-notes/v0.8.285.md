## English

### Highlights

- Added Dashboard loading placeholders for statistics, activity, outputs, and filters. Cached content stays visible during background refreshes; placeholders follow the current theme and reduced-motion preference.
- Unified connector app details across chat requests and the connector catalog. Pending setup requests keep the full details view, and linked services share the intended configuration while preserving request ownership and completion checks.
- Fixed duplicated assistant messages in native chat history for providers that send the full text in both start and completion events. Refreshing existing conversations now shows one message per text segment while retaining separate segments and turns.
- Improved Codex compatibility with Shoggoth-managed third-party model sources by disabling unsupported hosted web search for those sessions. Shoggoth-configured search tools remain available.
- Added bounded cloud-runner recovery and optional automatic publication after source checks, Developer ID signing, notarization, and both native acceptance jobs pass. Release notes remain English first, then Simplified Chinese.

## 简体中文

### 更新内容

- Dashboard 的统计、活动、产出和筛选区域新增加载占位。后台刷新时继续显示缓存内容，占位适配当前主题和减少动态效果的系统偏好。
- 聊天请求与连接器目录共用应用详情。待配置请求保留完整详情，多项关联服务共用对应配置，同时保留请求归属和完成状态检查。
- 修复部分 Provider 在开始与完成事件中都返回全文时，原生聊天历史重复显示助理回复的问题。已有会话刷新后按文本段保留一条消息，不合并不同文本段或不同轮次。
- 改善 Codex 对 Shoggoth 管理的第三方模型来源的兼容性，为这些会话关闭不受支持的托管网页搜索。Shoggoth 中已配置的搜索工具继续可用。
- 云端发布新增有限次数的机器分配故障恢复，并可在源码检查、Developer ID 签名、公证及双架构原生验收通过后自动正式公开。更新说明继续完整英文在前、简体中文在后。
