## English

### What's new

- Create a recurring follow-up from a native assistant in a group chat. When there is a new finding with a source link, the assistant posts it back to the same group.
- Remove a saved memory while keeping your current conversation and pending choices available. Removed material stays out of memory recall and automatic summaries.
- Web tools validate public destinations and keep TLS verification enabled on compatible HTTPS DNS proxy routes.
- Desktop controls resist accidental text selection, while message text, inputs, code, and reports stay selectable.
