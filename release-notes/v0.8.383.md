## English

- Connect Google Workspace through the official CLI, complete sign-in from the desktop, and see clearer messages when Google limits preview access.
- Manage usage reporting in Settings. Manually saved diagnostics now include failure stages, counts, and recent timestamps.
- Honor telemetry and error-reporting opt-out settings when launching Claude Code.
- Recover stale memory catalog locks after process IDs are reused, and include dates in nightly-review messages so relative times resolve correctly.

## 简体中文

- 通过官方 CLI 连接 Google Workspace，可在桌面端完成登录。遇到 Google 预览权限限制时，会显示更明确的提示。
- 可在设置中管理使用数据分享。手动保存的诊断文件现在会记录故障环节、发生次数和最近时间。
- 启动 Claude Code 时遵守用户对遥测和错误报告的退出设置。
- 修复进程 ID 复用后记忆目录锁无法恢复的问题，并为夜间复盘消息补充日期，以便正确理解相对时间。
