## English

### Highlights

- **Agent files and chat.** Agent files are organized in one panel, with easier access to settings, managed files, and run files. Chat agents can use a preset avatar or an uploaded image. Attachment copying and quoting preserve the original file.
- **Group chat.** Member cards handle offline availability more consistently. Group deletion can proceed when an external runtime is offline, with a separate confirmation for forced deletion.
- **Scheduled tasks and proactive checks.** Open the latest run from its chat card, edit a task from the list, and filter by agent. Proactive checks can use recent conversation history. Native agents keep their Main sessions and use the full eligible SOUL and USER context within the configured budget.
- **Management and connectors.** Loading and refresh states were refined across management pages. The connector recommendations now include HeyGen HyperFrames.

## 简体中文

### 更新内容

- **助理文件与聊天。** 助理文件集中到一个面板，方便访问设定、托管文件和运行文件。聊天助理支持预设头像和上传图片。复制或引用附件时保留原始文件。
- **群聊。** 成员卡片统一处理离线状态。外部运行时离线时也可删除群聊，强制删除仍需单独确认。
- **定时任务与主动检查。** 从聊天卡片打开最近一条运行记录，从列表直接编辑任务，并按助理筛选。主动检查可以读取近期对话历史。原生助理保留主会话，并在配置的预算内使用符合条件的完整 SOUL 和 USER 上下文。
- **管理页与连接器。** 改进多处管理页的加载和刷新状态。连接器推荐新增 HeyGen HyperFrames。
