## English

### What’s new

- Ask a native assistant in chat to watch a public webpage or feed and notify the original conversation when your condition is met. The assistant can test the condition before enabling it and can review a match before posting if you ask it to.
- Hermes conversations resume with their earlier context more reliably. The model picker shows the capabilities reported for supported models.
- Chat provides clearer recovery steps when a runtime fails to start, cannot read its login status, or cannot compact the conversation. When a manual retry is appropriate, the message explains how to use `/compact` before resending.
- Configure or dismiss MCP setup requests directly from chat. The cards show which connector still needs sign-in or setup. The chat composer layout has also been improved.
- Fix editing command-based Cron jobs so the command and its settings are preserved.

## 简体中文

### 更新内容

- 可以在聊天中请原生助理监测公开网页或订阅源，满足条件时通知原会话。启用前可以先试跑，也可以要求助理复核命中结果后再发送。
- Hermes 恢复聊天时能更可靠地接续原有上下文。模型选择器会展示受支持模型上报的能力。
- 运行环境启动失败、无法读取登录状态或无法压缩上下文时，聊天会显示更明确的恢复步骤。适合手动重试时，会提示如何先执行 `/compact` 再重发消息。
- 可以直接在聊天里处理或关闭 MCP 配置请求。卡片会标出仍需登录或配置的连接器，同时改进了聊天输入区布局。
- 修复命令型 Cron 任务编辑时的命令及参数保留问题。
