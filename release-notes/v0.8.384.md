## English

- Fixed a memory storage startup issue after an older catalog lock's process ID was reused by a different macOS user, including when the original Service lock is missing. The Service still checks lock ownership before recovery.

## 简体中文

- 修复旧版记忆目录锁的进程 ID 被其他 macOS 用户复用后导致的启动问题，包括原 Service 锁已缺失的情况。Service 在恢复前仍会核对锁的归属。
