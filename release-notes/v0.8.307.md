## English

### Highlights

- **Agent models and management.** Agent model selectors share a unified catalog. Management cards are simpler, and group creation and member selection use the same picker.
- **Native chat.** The app prepares more of the send path in the background, reducing the work that has to finish before a message can start.
- **Agent files and memory.** Agent definitions live in dedicated files with up to three backups. Native agents can edit their own HEARTBEAT, USER, and MEMORY files. Memory flushes and nightly reviews handle interrupted or repeatedly failing work more reliably.
- **Proactive checks.** Native proactive checks can use the main conversation's context and report back to that conversation.
- **macOS installer and web access.** The DMG has an updated Finder layout. Web tools validate HTTPS certificates, protect provider credentials from redirects, and restrict direct access to public targets.

## 简体中文

### 更新内容

- **助理模型与管理。** 助理的模型选择统一使用一份目录。管理卡片更简洁，新建群聊和选择成员使用同一套选择器。
- **原生聊天。** 应用在后台提前完成更多发送准备工作，缩短从发送消息到开始执行的等待。
- **助理文件与记忆。** 助理设定存放在专用文件中，最多保留三份备份。原生助理可编辑自己的 HEARTBEAT、USER 和 MEMORY 文件。记忆写回和夜间复盘改进了中断及重复失败后的处理。
- **主动检查。** 原生助理的主动检查可以使用主会话上下文，并将结果返回该会话。
- **macOS 安装包与联网。** 更新了 DMG 的 Finder 布局。联网工具验证 HTTPS 证书，防止重定向转发服务商凭据，并将直接访问限制在公网目标。
