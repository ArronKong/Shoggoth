## English

### What's new

- Live activity bubbles in direct, immersive, and group chats expand to show current steps. Group chats keep your reading position while you browse earlier messages.
- Native scheduled jobs can save text reports directly to an assistant's Files. Reports from separate runs remain available as separate files, even when they share a name.
- Edit the command and arguments for OpenClaw scheduled command jobs from the existing edit dialog.
- Bundled Codex recovers from interrupted model requests, and Grok handles transient failures before the first output more reliably.
