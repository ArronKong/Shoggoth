## English

- Background tasks now support OpenCode, DeepSeek Harness, and Antigravity alongside Codex and Pi. Follow-up requests can stay queued until the task can accept them.
- Task details show the child conversation and its live tool activity. Review questions and approvals, send follow-ups, or stop the task there. Reports display Markdown and attachments in both chat layouts and link back to task details.
- The new Product Hunt connector can look up public launches and products. Sign in through the connector to use actions that require your Product Hunt account.
- OAuth quota results are saved by account so the last verified reading is available after restart. Recovered chat runs keep tool activity in the same timeline entry.
- The bundled Codex Harness and its App Server protocol have been updated to 0.170.0.

## 简体中文

- 后台分身在 Codex 和 Pi 之外新增对 OpenCode、DeepSeek Harness 和 Antigravity 的支持。追加要求可先排队，等任务可接收时再送达。
- 任务详情可查看子会话和实时工具动态，处理提问与审批、追加要求或停止任务。普通和沉浸聊天均可显示 Markdown 报告及附件，并可回到对应的任务详情。
- 新增 Product Hunt 连接器，可查询公开的产品和发布动态。需要使用账号权限的操作时，可从连接器登录授权。
- OAuth 额度按账号保存，重启后可查看上次核验的结果。聊天回合恢复后，同一工具的动态会继续更新原来的条目。
- 随 App 分发的 Codex Harness 和 App Server 协议更新至 0.170.0。
