## English

### What's new

- Creating a native scheduled task now needs only a name, a prompt, and a schedule. Listing tasks and looking up a task take fewer arguments. Help and validation messages include examples.
- When Antigravity has a confirmed failed context checkpoint, the next chat message or scheduled run can open a fresh runtime session while keeping the original conversation and run history. Scheduled tasks can carry forward recent completed reports.
- The dashboard shows the name of a running scheduled task and adds its result to the activity feed once it is ready. Chat keeps the compact loader during routine startup, and live and historical tool activity use the same readable labels.
- macOS releases can reuse CI from the merged source PR when it tested the exact release tree. Intel first-launch verification allows more time for its cold-start self-test. Both architectures still pass signing, notarization, and native launch verification before publication.

## 简体中文

### 更新内容

- 创建原生定时任务只需填写名称、提示和计划。列出任务和查看任务详情所需的参数更少，帮助与参数校验提示都提供示例。
- Antigravity 确认上下文检查点失败后，下一条聊天消息或定时运行可以开启新的运行时会话，同时保留原会话和运行记录。定时任务可以接续近期已完成的报告。
- 总览显示正在运行的定时任务名称，结果就绪后再收录到动态列表。聊天常规启动期间保持简洁的等待指示，实时和历史工具活动采用同一套易读名称。
- macOS 发布可复用已合并源码 PR 对同一 Git 树的 CI 结果。Intel 首启验收为冷启动自测预留更多时间。两个架构均须通过签名、公证和原生启动验收才会公开发布。
