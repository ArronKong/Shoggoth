## English

- Start background tasks from a direct chat on supported Codex and Pi runtimes and continue the conversation while they run. Review progress, answer questions, approve actions, and open reports from the task card in the original chat.
- Native Agents can use a persistent workspace across conversations. Chat attachments are copied into each recipient Agent's workspace for editing while the original stays in chat history.
- The Models page shows the last successful quota result immediately and refreshes it in the background. Account changes clear the old cache.
- Scheduled tasks can use a selected model and show why a run was skipped. Direct chat adds a message navigator and can send immediately when the conversation is idle.
- Product statistics are on by default in this desktop release. Saved preferences carry over on upgrade. Both controls are available under Settings → Privacy and statistics.

## 简体中文

- 使用支持后台分身的 Codex 或 Pi 时，可从私聊派工并继续在前台对话。在原聊天的任务卡上可查看进度、回答问题、审批操作和打开报告。
- 原生助理可以跨会话使用长期工作区。聊天附件会复制到收件助理的工作区以便编辑，历史中的原件会保留。
- 模型页会立即显示上次成功取得的额度并在后台刷新。切换账号时会清除旧缓存。
- 定时任务可以选择模型，也会显示跳过运行的原因。单聊加入消息导航，空闲时可以直接发送。
- 本桌面版默认开启产品统计。升级会保留已保存的偏好，两项开关都在「设置 → 隐私与统计」。
