## English

### What's new

- Download available Shoggoth updates from the navigation bar and see download progress in the app.
- See when an assistant inherits its default model. This release also improves assistant management and chat context handling, updates the bundled Codex runtime to 0.167.1, and isolates Codex provider runtime settings.
- Open Alipay authorization in the system browser and refresh authorization from the connector dialog. The NetEase Music connector has been removed.
- Find product statistics controls and bilingual privacy notices under Settings. Sending product statistics to PostHog stays disabled in this build.

### macOS downloads

- Apple Silicon: `Shoggoth-0.8.311-arm64.dmg`
- Intel: `Shoggoth-0.8.311-x64.dmg`

## 简体中文

### 更新内容

- 可以从导航栏下载 Shoggoth 更新，并在应用内查看下载进度。
- 可以查看助理是否继承默认模型。改进了助理管理与聊天上下文处理，将内置 Codex 运行时更新到 0.167.1，并隔离 Codex 供应商运行时配置。
- 支付宝授权改用系统浏览器打开，可在连接器弹窗刷新授权。移除了网易云音乐连接器。
- 设置新增产品统计开关和中英双语隐私说明。本版保持关闭向 PostHog 发送产品统计。

### macOS 下载

- Apple 芯片：`Shoggoth-0.8.311-arm64.dmg`
- Intel 芯片：`Shoggoth-0.8.311-x64.dmg`
