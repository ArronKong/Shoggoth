## English

- The app can run the official Claude Code CLI you have installed. It reuses a process for follow-up messages in the same session and resumes the session after an idle timeout.
- Claude sessions support context compaction and Shoggoth background tasks. The model picker shows the resolved default model while keeping saved model selections usable.
- Fixed the MCP initialization handshake for newer Claude Code clients and restored the Shoggoth-designed avatar for the built-in agent.
- Fixed chat startup when all supported native CLI accounts are installed.

## 简体中文

- 应用恢复运行本机已安装的官方 Claude Code CLI。同一会话的后续消息复用进程，空闲退出后可以续接原会话。
- Claude 会话支持上下文压缩和 Shoggoth 后台任务。模型菜单显示实际默认模型，并兼容已保存的模型选择。
- 修复较新 Claude Code 客户端的 MCP 初始化握手，并恢复 Shoggoth 为内置 Agent 设计的头像。
- 修复装齐所有支持的原生 CLI 账号时聊天无法启动的问题。
