## English

- View context usage and a breakdown from the chat composer in standard and immersive chats. Compact supported conversations from the same panel.
- Native runtimes reuse unchanged instructions and context. Manual and automatic compaction and continuation work more reliably across Codex, Claude Code, Antigravity, OpenCode, Grok Build, Pi, and DeepSeek. Reopened Grok Build chats can recover the token usage from completed turns.
- Completed or stopped messages recover their receipts after temporary history or connection failures without sending a duplicate. Interrupted encryption workers recover safely, and Antigravity shows clearer balance errors and more up-to-date tool activity.
- Added the Obsidian desktop CLI connector with seven official skills, restored Google Workspace to recommended connectors, and kept the message navigator visible above the chat docks.
- Older retained history stays accessible after withdrawing a remembered fact.

## 简体中文

- 普通和沉浸聊天的输入框可以查看上下文用量和分项明细，也可以在同一面板压缩受支持的会话。
- 原生运行时会复用未变化的指令和上下文。改进 Codex、Claude Code、Antigravity、OpenCode、Grok Build、Pi 和 DeepSeek 的手动压缩、自动压缩和续聊。重新打开 Grok Build 聊天时，可恢复已完成回合的用量。
- 已完成或已停止的消息在历史读取或连接短暂失败后会恢复发送回执，避免重复发送。改进加密进程中断后的恢复，以及 Antigravity 的余额错误提示和工具动态。
- 新增 Obsidian 桌面 CLI 连接器和七个官方技能，将 Google Workspace 恢复到推荐连接器，并让消息导航浮在聊天面板上方。
- 撤回一条记忆后，仍可查看此前保留的较早历史。
