## English

- Updated the official Antigravity ACP server to 1.5.2. Existing 1.4.3 installations remain usable until the verified update is available.
- The Models page shows usage limits and reset times for the account signed in to the local Antigravity CLI.
- Unified discovery of installed CLIs across native runtimes. The local-tool cards in Settings focus on readiness and connection actions, while keeping the warning about sessions that cannot be resumed.
- Inspiration reminder links open the corresponding note inside Shoggoth.
- Cloud releases can retry an unassigned macOS CI job, resume a notarization check by submission ID, and retry individual E5 downloads.
- Updated the UI translation dependency to i18next 26.3.4 to address a security advisory.

## 简体中文

- 官方 Antigravity ACP 服务端更新至 1.5.2。已安装的 1.4.3 可以继续使用，直到新版下载并通过校验。
- 模型页可查看本机 Antigravity CLI 登录账号的使用额度和重置时间。
- 统一原生运行时的本机 CLI 查找规则。设置页的本机工具卡片集中展示就绪状态与连接操作，并保留历史会话无法续接的提示。
- 灵感提醒链接会在 Shoggoth 内打开对应便签。
- 云端发布支持补跑未分配 runner 的 macOS CI 作业、按提交编号续查公证结果，以及单独重试 E5 文件下载。
- 界面翻译依赖更新至 i18next 26.3.4，修复已披露的安全问题。
