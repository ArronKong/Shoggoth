## English

### What’s new

- Chat preserves message drafts and attachments when storage is full. When a send may already have been accepted, chat checks its original receipt so you can recover it without sending a duplicate.
- Hermes scheduled-task failures are visible in chat history. When a failure can be matched to its scheduled run, chat explains the cause, such as a daily quota limit, an authentication error, or a timeout. It also flags runs that may have already taken some actions. Run the task again from Scheduled Tasks.
- In chat timeline details, only entries with additional content can be expanded. Connector names in the setup dialog can now be selected and copied.
- Fix MCP connector authentication after the local cache has been cleared.

## 简体中文

### 更新内容

- 磁盘空间不足时，聊天会保留消息草稿和附件。发送结果不明确时，会查询原发送回执，帮助恢复原请求，避免重复发送。
- Hermes 定时任务失败后，聊天历史会保留失败提示。能匹配到对应运行记录时，会说明原因，例如当天额度耗尽、身份验证失败或连接超时。如果任务可能已执行部分操作，也会显示提醒。可在「定时任务」中重新运行。
- 聊天时间线详情中，有补充内容的条目才可展开。连接器配置弹窗里的名称现在可以选中并复制。
- 修复清除本地缓存后 MCP 连接器身份验证失败的问题。
