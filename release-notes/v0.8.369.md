## English

- Native chat updates the reasoning effort in the slider and composer immediately in both regular and immersive views. Model and effort changes save in order within each session. A failed save restores the last saved setting and keeps the draft.
- Inspiration note fields stay transparent while focused and while you type, in both the main window and the desktop quick-note window.

## 简体中文

- 原生聊天的滑杆和输入框会即时显示选中的思考档位，普通和沉浸聊天均适用。同一会话内按顺序保存模型和档位。保存失败时恢复上次保存的设置，并保留草稿。
- 灵感便签的输入区在聚焦和输入时保持透明，主窗口和桌面快捷便签均适用。
