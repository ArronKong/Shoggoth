## English

### What’s new

- Native chat confirms receipt sooner, keeps messages ordered within each conversation, and prepares independent conversations concurrently within account limits. Refreshing or reconnecting restores the original send or stop result and avoids duplicate messages.
- Chat distinguishes context preparation, account capacity, and recovery. When a runtime needs a new thread, structured continuation can carry selected messages and text attachments into the next request with their source references.
- Memory reads and Codex Desktop session discovery do more work in the background, keeping chat and cancellation responsive. Ordinary Dreaming updates preserve valid context, while corrections, forgetting, and revoked sources are checked before use.
- Group chat retains replies that have already arrived while it reconnects. Scheduled reports retain their delivery and deduplication rules, including after a restart.
- Improve macOS upgrade checks for the signed app and its renderer helpers.

## 简体中文

### 更新内容

- 原生聊天更早确认已接收消息，同一会话保持顺序，独立会话在账号容量内可以并行准备。刷新或重连后可恢复原发送或停止结果，避免重复消息。
- 聊天会区分准备上下文、等待账号名额和正在恢复。运行时需要更换线程时，可通过结构化接续把选定的消息和文本附件连同来源引用带入下一次请求。
- 记忆读取和 Codex Desktop 会话发现将更多工作移至后台，聊天状态和取消操作可以继续响应。例行 Dreaming 更新保留有效上下文，使用前仍会核对更正、遗忘和已撤回的来源。
- 群聊重连时保留已收到的回复。定时报告在重启后仍遵守原投递和去重规则。
- 改进 macOS 升级前对签名 App 和渲染进程组件的检查。
